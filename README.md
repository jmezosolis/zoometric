# Zoometric

Zoometría por visión por computadora a partir de una foto lateral del animal: área lateral, altura a la cruz y a la grupa, profundidad de tórax y longitud corporal, con exportación a Excel para correlacionar con el peso.

**App:** https://jmezosolis.github.io/zoometric/ — instalable en el celular y funciona sin internet.

Este repositorio contiene la app tal como se publica; sus archivos son su código fuente.
